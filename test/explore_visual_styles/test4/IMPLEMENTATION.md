# Implementation

**Spec:** [SPEC-002-RAVEN-CITY.md](SPEC-002-RAVEN-CITY.md)

**Method:** procedural vector illustration (SVG). The same set of raven, spire, antique key and four building silhouettes was rendered under different style-specific color and contour treatments. The original source is each SVG file.

- **German:** limited ink-and-paper palette, heavy shadows, tilted skyline, carved slashes.
- **Constructivist:** red/black/cream geometric design and diagonals.
- **Psychedelic:** saturated fluid repeat patterns and warped spatial cues.
- **Hybrid v1:** expressionist black masses with separate psychedelic bands.
- **Hybrid v2:** removed detached ornaments, clipped color currents to wing/body/city structures and visibly joined beak to key ring.

All artwork is original and editable. Illustrations are **not** image-model raster generations. A separate image-model attempt yielded an unrelated documentation screenshot rather than the requested artwork, so it was rejected and is **not** scored as a valid study.

**Verification:** follow the spec's Acceptance Criteria in [REVIEW.md](REVIEW.md). Output format is 900 × 1200 SVG, viewable directly on GitHub. An independent PNG preview can be rasterized from the final SVG.
