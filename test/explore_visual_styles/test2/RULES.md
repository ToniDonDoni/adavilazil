# Hybrid acceptance rules (before hybrid generation)

**Skill: EXPLORE-VISUAL-STYLES | Version: 1.0.0**

Subject stays constant: recognizable black raven, antique gold key, city skyline.

| ID | Rule | Visible pass condition |
| --- | --- | --- |
| F | Form | At least one wing and the raven's neck transition from carved angular facets into curved ribbons **inside the anatomy**. |
| C | Color | Magenta/orange/violet distort the raven, not just background; near-black shadows dominate. |
| L | Line | Rough irregular cut marks and smooth flowing lines visibly join on the same surfaces. |
| S | Space | Skyline and perspective twist along the same current as the raven's silhouette, not a separate decorative layer. |
| K | Composition | Asymmetric, tense visual path moves between raven's eye, key and skyline. |
| T | Texture | Distressed analog print/woodcut texture clearly visible across both bird and scene. |
| E | Emotion | Fascination and unease simultaneously; avoid cute mascot and heroic celebration. |
| R | Readability | Raven silhouette and golden key obvious at thumbnail scale. |

Review each ID using **pass / partial / fail**, citing what is actually in the image. In revision only target weak/failed rules and compare new results.
