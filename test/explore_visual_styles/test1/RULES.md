# Test 1: rules set before rendering

**Subject:** one black raven holds a recognizably golden key, in a warped city. **Mix:** German Expressionist woodcut + 1960s psychedelic poster. Shared principle: both distort reality to communicate emotion.

| Rule | Observable acceptance condition |
| --- | --- |
| Form | Wing or body angles visibly turn into flowing curves within the same object. |
| Color | Magenta, violet and yellow modify the raven itself; shadows stay near-black. |
| Line | Rough, carved strokes intersect with continuous curves. |
| Space | Buildings and perspective bend with the same visual rhythm. |
| Composition | Unstable asymmetric focus leads eye from raven to key. |
| Texture | Visible imperfect print or carved marks, not smooth vector-only surfaces. |
| Emotion | At least tension and fascination, not purely cute or triumphant. |
| Subject | Raven and large golden key remain readable without the caption. |
