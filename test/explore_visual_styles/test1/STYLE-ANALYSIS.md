# Style analysis: raven and key

This is a **retrospective reconstruction** of the style analysis missing before v1. The source notes are [German Expressionist poster](../../../reference/visual_styles/german_poster/) and [psychedelic poster](../../../reference/visual_styles/psychedelic_poster/).

| Feature | German Expressionist print | 1960s psychedelic poster | Hybrid rule for the raven |
| --- | --- | --- | --- |
| Light | Hard chiaroscuro | Vibrating contrasts | Black shadow frames intense color from within |
| Color | Restricted and stark | Saturated, unusual pairings | Magenta/violet/gold penetrate dark feathers |
| Form | Jagged, distorted angles | Melting organic curves | Angular wing feathers become ribbons |
| Line | Rough carved strokes | Continuous fluid line | Cuts transition into flowing contours |
| Space | Emotional distortion | Optical warped perspective | City buildings bend with the wing's rhythm |
| Composition | Tense, dramatic thrust | Repeating waves | Asymmetric movement from bird to key |
| Texture | Rough ink/woodcut | Print grain | Distressed print surface with irregular cuts |
| Emotion | Anxiety, urgency | Wonder, altered perception | Fascination and unease at the same time |

**Shared principle:** both distort reality for emotion. The fusion changes the *same objects*, not separate foreground and background layers. See measurable criteria in [RULES.md](RULES.md).

**Missing evidence:** the required three separate style generations and the original reference moodboards were not created for this test. Do not treat this reconstructed analysis as proof they occurred.
