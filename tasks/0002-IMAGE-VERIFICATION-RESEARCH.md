# Task 0002: Image Verification Research

**Status:** backlog

## Task

Research existing approaches to evaluating generated images against explicit, observable acceptance criteria. Compare their fit with the repository's [Explore Visual Styles](../skills/EXPLORE-VISUAL-STYLES.md) workflow. This is a future research task, **not an implementation request**.

## Projects to investigate

- [autocritic](https://github.com/mccoyspace/autocritic): theory-driven critic cards, structured visual critique, and optional improvement loops.
- [AHD](https://github.com/Ad-Astra-Computing/ahd): design-failure taxonomy, style tokens, brief compilation, and reproducible evaluation.
- [image-generation](https://github.com/eandrei/image-generation): generator, evaluator, and prompt-refinement loop.
- [ProImage-Bench (TechImage-Bench repository)](https://github.com/kodenii/TechImage-Bench): rubric-based evaluation of professional image-generation tasks.

## Expected result

A concise comparison of relevant ideas, limitations, and possible applications to spec-based visual verification. Do not duplicate the repository's existing specification or style authoring rules.
