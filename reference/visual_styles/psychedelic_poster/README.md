# Psychedelic poster

**Origin:** 1960s counterculture, especially San Francisco concert posters.

- **Light:** vibrating color contrasts.
- **Color:** saturated, unusual pairings.
- **Form:** fluid curves, warped lettering.
- **Texture:** analog print grain, repeated patterns.

**Mood:** wonder, sensory overload, altered perception.

**Find:** `1960s psychedelic concert poster`, `San Francisco psychedelic art`, `psychedelic lettering`.

**Sources:**
- [Cooper Hewitt: Deliberately Disorienting](https://www.cooperhewitt.org/2018/10/23/deliberately-disorienting/) (Wes Wilson example; sinuous lettering, dense composition).
- [Cooper Hewitt: Psychedlic Promotion](https://www.cooperhewitt.org/2013/12/16/psychedlic-promotion/) (San Francisco origins, Art Nouveau and Op Art influences).
