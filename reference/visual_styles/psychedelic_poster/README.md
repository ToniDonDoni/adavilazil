# Psychedelic Poster

## Origin
1960s counterculture concert posters, especially San Francisco.

## Background
Fluid ornament, saturated color and optical rhythm suggest altered perception. The requirements describe a practical visual-language study.

## Style Requirements
- **PP-01 Light:** Use contrasting colored light zones rather than neutral shading.
- **PP-02 Color:** Place at least three saturated, visibly contrasting hues.
- **PP-03 Form:** Bend recognizable shapes into fluid organic curves.
- **PP-04 Line:** Use repeating, continuous wave-like contours.
- **PP-05 Space:** Distort depth with ripples, spirals or warped perspective.
- **PP-06 Composition:** Carry the viewer's eye along a repeating visual rhythm.
- **PP-07 Texture:** Show analog print grain or imperfect color registration.
- **PP-08 Mood:** Suggest wonder or sensory disorientation through the distortion.
