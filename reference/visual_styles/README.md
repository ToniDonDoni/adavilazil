Use the [style template](../../engineering/STYLE-TEMPLATE.md). Each entry has **Overview**, **Influenced By**, **Influenced To**, **Relations**, flexible visually testable **Style Requirements**, and **Sources**.

Write influence and relations as plain text. Linking to an existing catalog entry is optional. The requirement list is not a fixed set of categories or IDs. Distinguish historical evidence from modern artistic adaptations.
