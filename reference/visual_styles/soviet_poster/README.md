# Soviet Constructivist poster

**Origin:** Soviet Constructivism, 1920s.

- **Light:** flat, graphic tonal blocks.
- **Color:** red, black, cream; few accents.
- **Form:** geometry, diagonals, photomontage.
- **Texture:** screenprint, halftone, paper grain (practical digital recreation).

**Mood:** momentum, collective action, public announcement.

**Find:** `Soviet Constructivism poster`, `Rodchenko photomontage`, `1920s constructivist graphic design`.

**Sources:**
- [University of Michigan Museum of Art: Soviet Constructivist Posters](https://umma.umich.edu/exhibitions/soviet-constructivist-posters-branding-the-new-order/) (1920s posters, bold colors and dynamic composition).
- [MoMA: Rodchenko, Graphic Design](https://www.moma.org/interactives/exhibitions/1998/rodchenko/texts/graphic_design.html) (constructivist mass-media and advertising practice).
