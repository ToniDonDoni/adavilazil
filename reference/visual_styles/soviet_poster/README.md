# Soviet Constructivist Poster

## Origin
Soviet Constructivist graphic design, especially 1920s poster and advertising work.

## Background
Geometric arrangements and montage communicate action. This is a reproducible digital poster adaptation.

## Style Requirements
- **SC-01 Light:** Use flat graphic light/dark blocks, not modeled shading.
- **SC-02 Color:** Make red, black and cream the dominant palette.
- **SC-03 Form:** Construct focal elements from triangles, bars or circles.
- **SC-04 Line:** Prefer crisp straight edges and hard diagonals.
- **SC-05 Space:** Flatten the scene into visibly overlapping planes.
- **SC-06 Composition:** Use an off-center diagonal as the main direction.
- **SC-07 Texture:** Add a visible halftone or misregistered print patch.
- **SC-08 Mood:** Convey urgency through scale, cropping and direction.
