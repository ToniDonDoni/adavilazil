# German Expressionist poster

**Origin:** German Expressionism, early 20th century; expressionist printmaking.

- **Light:** hard chiaroscuro, deep shadows.
- **Color:** restricted, high contrast.
- **Form:** jagged angles, distorted proportions.
- **Texture:** carved woodcut strokes, rough ink.

**Mood:** anxiety, urgency, psychological intensity.

**Find:** `German Expressionist woodcut poster`, `Die Brücke prints`, `expressionist linocut`.

**Sources:**
- [MoMA: German Expressionism woodcut](https://www.moma.org/s/ge/curated_ge/techniques/woodcut.html) (technique, rough cuts and black-white contrast).
- [MoMA: Die Brücke](https://www.moma.org/s/ge/curated_ge/styles/brucke.html) (origin, distorted shapes and emotional color).
